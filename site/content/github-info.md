## Agentic workflows to know

GitHub's [Agentic Workflows](https://github.github.com/gh-aw) project (via the `gh aw` CLI extension) packages AI-powered repository automations as markdown files with natural language instructions, compiled into GitHub Actions. Notable examples from the Awesome Copilot collection:

- Daily Issues Report: a scheduled summary of open issues and recent repo activity.
- Weekly Comment Sync: finds stale code comments or README snippets and opens a draft PR with text-only fixes.
- Relevance Check: a slash command that evaluates whether an issue or PR is still relevant to the project.
